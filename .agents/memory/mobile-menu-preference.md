---
name: Mobile menu navigation preference
description: User feedback on how menu categories should behave on narrow phones.
---

Keep the menu navigation thin and persistent while browsing, with every category visible at once and a prominent indicator that follows the current section. Avoid requiring a sideways swipe to discover categories.

**Why:** The user liked the compactness of the earlier one-row design but explicitly wanted all options visible without scrolling and a thick bar that stays with customers.

**How to apply:** When adjusting the menu navigation, preserve at-a-glance access to every category on narrow phones rather than trading it for horizontal scrolling.

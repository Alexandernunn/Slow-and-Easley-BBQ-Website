Build a fast, SEO-optimized, mobile-first website for "Slow & Easley BBQ & Soul Food," a Tennessee BBQ and soul food restaurant. PAGE SPEED AND GOOGLE SEO ARE THE TOP PRIORITIES. Every design decision must serve those two goals first. You have creative freedom on layout and design within the rules below.

=== PRIORITY 1: PAGE SPEED (NON-NEGOTIABLE) ===
Target: 95+ on Google PageSpeed Insights for both mobile and desktop, and passing Core Web Vitals (LCP under 2.5s, CLS under 0.1, INP under 200ms).
- Use a static-first approach: plain HTML/CSS with minimal vanilla JS, or a static site generator (Astro preferred). No heavy frameworks, no jQuery, no animation libraries.
- Keep total page weight under 1MB and JavaScript under 50KB.
- Fire/smoke/ember effects must be done with pure CSS (gradients, keyframes, transforms, opacity only). No video backgrounds, no GIFs, no canvas particle libraries, no animations that trigger layout or repaint.
- Images: serve WebP/AVIF with JPEG fallback, use responsive srcset and sizes, set explicit width and height on every image to prevent layout shift, lazy-load everything below the fold, and preload the hero image with fetchpriority="high".
- Fonts: maximum 2 font families, self-hosted as WOFF2, subset to Latin, font-display: swap, and preload the display font. If a grunge texture is wanted on the logo, use a lightweight SVG or CSS mask instead of a heavy texture font.
- Inline critical above-the-fold CSS; load the rest non-blocking. Minify all HTML, CSS, and JS.
- No render-blocking third-party scripts. The Google Map must be a static image or click-to-load facade, not an iframe on page load.
- Respect prefers-reduced-motion by turning off all animations.

=== PRIORITY 2: GOOGLE SEO ===
- Semantic HTML5: one H1 ("Slow & Easley BBQ & Soul Food"), logical H2/H3 hierarchy for each menu section, proper <header>, <nav>, <main>, <section>, <footer>.
- Unique title tag (under 60 characters), e.g., "Slow & Easley BBQ & Soul Food | Tennessee BBQ & Fried Fish".
- Meta description (under 155 characters) mentioning smoked BBQ, fried whitefish, soul food, and the city (use a [CITY] placeholder).
- Menu must be real crawlable HTML text, never an image or PDF.
- JSON-LD structured data: Restaurant schema (name, address, phone, hours, servesCuisine: "Barbecue", "Soul Food", priceRange: "$", menu URL, geo coordinates) plus Menu/MenuSection/MenuItem schema with every item and price. Use placeholders for address, phone, hours, and coordinates.
- Open Graph and Twitter Card tags with a placeholder share image (1200x630).
- Canonical URL, robots.txt, sitemap.xml, and favicon/apple-touch-icon.
- Descriptive alt text on every image (e.g., "Smoked chicken wings with ranch at Slow & Easley BBQ").
- Clean, descriptive URLs if using multiple pages (/menu, /about, /contact).
- Consistent NAP (name, address, phone) in the footer on every page, matching the schema, for local SEO.
- Click-to-call phone link using tel: format.
- Include local keywords naturally in the About section copy (Tennessee BBQ, soul food, fried whitefish, smoked wings, [CITY]).
- Accessibility: WCAG AA contrast, visible focus states, aria labels on icon buttons. Aim for 100 on Lighthouse Accessibility and SEO.

=== BRAND & VISUAL STYLE ===
- Palette: deep black (#0a0a0a) backgrounds, bold red (#d91f26) accents, white text. Orange/amber only as a subtle glow for flame effects.
- Theme: Tennessee BBQ smokehouse. Smoke, embers, and flames, done lightly with CSS so they never compete with the content or hurt load time.
- Include a Tennessee state silhouette outlined in red as an inline SVG (hero badge, logo lockup, or footer).
- Typography: a bold condensed display font for headings (e.g., "Bebas Neue" or "Oswald") and a clean readable font for body text. Section headers styled as red brush-stroke banners with black text (use a lightweight inline SVG or CSS shape for the brush stroke).
- Feel: bold, smoky, confident, down-home. Not corporate.

=== SECTIONS (single page with sticky nav is fine) ===
1. Hero: H1 restaurant name, "BBQ & Soul Food" tagline, CSS flame glow, CTAs "View Menu" and "Call to Order."
2. Menu: Entrées, Sandwiches, Sides, Add-Ons, Desserts, BBQ Sauces. Menu-board style with dotted leaders between item name and price. Pull all menu content from a single data file so prices are easy to update, and generate both the HTML and the JSON-LD menu schema from that same file.
3. About: short story about slow-smoked Tennessee BBQ and scratch-made soul food (placeholder copy with local keywords).
4. Hours & Location: placeholder address, hours, phone, and a static map image that links to Google Maps.
5. Footer: NAP, social icons (inline SVG), copyright.
- Sticky click-to-call button on mobile.
